# WONS ARCHIVE — Cinematic Portfolio

## GitHub Pages 배포

1. 이 ZIP을 압축 해제합니다.
2. `https://github.com/wondol2g-art/wons-archive` 저장소의 **최상위 폴더**에 `index.html`, `style.css`, `script.js`, `images/`를 업로드합니다. ZIP 파일이나 압축 해제한 상위 폴더 자체를 업로드하지 마세요.
3. 기존 파일을 덮어쓰고 **Commit changes**를 클릭합니다.
4. Settings → Pages에서 `main` 브랜치의 `/(root)`가 선택되어 있는지 확인합니다.
5. `https://wondol2g-art.github.io/wons-archive/`에서 확인합니다.

## 새 사진 추가

저장소 최상위의 `images` 폴더에 JPG, JPEG, PNG, WebP, GIF, AVIF 사진을 업로드한 뒤 Commit changes를 클릭합니다. 공개 저장소의 GitHub Contents API를 통해 갤러리가 새 파일을 자동으로 감지합니다. 사진은 `NEW PHOTOGRAPHS` 분류에 추가됩니다. `cover.png`는 표지로 사용되므로 갤러리에서 제외합니다.

주의: GitHub API가 일시적으로 제한되거나 연결되지 않으면 기본 17장만 표시될 수 있습니다. 저장소가 비공개면 자동 불러오기가 동작하지 않습니다. 이전에 만든 `WONS-ARCHIVE-Auto-Gallery` 하위 폴더는 사용하지 않습니다.

## 표지 교체

`images/cover.png`를 동일한 파일명으로 교체합니다. 표지에는 이전에 제작한 WONS ARCHIVE 표지 이미지를 사용했습니다.
