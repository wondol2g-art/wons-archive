# WONS ARCHIVE — GitHub Pages

크림색 미니멀 사진 포트폴리오. 제공된 사진 17장 수록.

## 배포
1. ZIP 압축을 풀고 `wons-archive` 폴더 안의 모든 파일(`index.html`, `style.css`, `script.js`, `images/`)을 GitHub 저장소의 최상위에 업로드합니다.
2. 저장소 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.
3. 몇 분 후 GitHub Pages 주소에서 확인합니다.

## 사진 추가
`images/` 폴더에 이미지를 넣고 `script.js`의 `photos` 배열에 src, title, location, category를 추가하세요.

원본 ZIP에는 예시 SVG 6장이 있었으며 실제로 접근 가능한 사진 17장으로 교체했습니다. CONTACT는 임의 이메일을 사용하지 않도록 ABOUT 섹션으로 연결했습니다.
