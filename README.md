# WONS ARCHIVE

Open `index.html` to browse the gallery. Scroll down to browse the photographs. Desktop rows show up to three photographs in their original proportions, with a maximum of two in any row containing a landscape image. Mobile shows one photograph per row. The gap between photographs is 8 px.

For GitHub Pages, upload `index.html`, `style.css`, `script.js`, and the `images/` folder to the publishing directory. The GitHub repository source for automatic photo discovery is set in `script.js`.
