# WONS ARCHIVE

Open `index.html` to browse the gallery. Scroll down to browse the photographs. Desktop rows show up to two photographs, and mobile shows one per row. The gap between photographs is 15 px.

For GitHub Pages, upload `index.html`, `style.css`, `script.js`, and the `images/` folder to the publishing directory. The GitHub repository source for automatic photo discovery is set in `script.js`.
